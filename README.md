# HylteKollen

[Öppna Hyltekollen](https://hyltekollen.karlsvenniklas.chatgpt.site/)

Detta repo länkar till den publicerade webbplatsen. Webbplatsens källkod och publicering hanteras fortfarande i ChatGPT Sites. Ändringar i det här GitHub-repot synkas eller publiceras inte automatiskt.

[Granskad kodkopia av Sites-version 66](https://github.com/karlsvenniklas-dot/HylteKollen/tree/sites-source-v66) – källkod utan protokollarkiv, ljud och skarp miljökonfiguration. Kopian publicerar inte sajten och kan inte byggas fristående utan underlaget.
